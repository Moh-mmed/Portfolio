## About

This is the source repository for the personal portfolio of **Mohammed Ben Aoumeur**: a fast, accessible showcase of full-stack product work, AI integrations, and the engineering decisions behind each project.

The experience is built to feel considered without getting in the way: browse all projects from the homepage carousel, then open individual case studies for the story behind the work.

## Highlights

- Responsive project carousel on desktop and an easy-to-scan mobile grid
- Individual project case studies with image galleries, technology stacks, and useful links
- Dark and light themes, motion preferences, keyboard-friendly navigation, and a contact form with validation and rate limiting
- SEO metadata, Open Graph cards, JSON-LD structured data, and optimized Next.js images
